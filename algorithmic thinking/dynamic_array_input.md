                                                                                        数组动态输入
一.数组长度固定，让用户输入内容

int arr[5] = {0}; // 先全部清零
cout << "请输入5个数字：";
for (int i = 0; i < 5; i++) {
    cin >> arr[i]; // 用户输入什么，就依次塞进第 i 个格子
}

二.数组长度也不固定，完全由用户决定（真正的动态）

方案A：开一个足够大的数组
int arr[100] = {0}; // 反正全初始化为0了，没用到的位置都是0
int n;
cout << "你要输入几个数字？";
cin >> n; // 用户输入实际长度，比如输入3

cout << "请输入这" << n << "个数字：";
for (int i = 0; i < n; i++) {
    cin >> arr[i]; // 循环只跑 n 次，只填前 n 个格子
}

// 打印看看
for (int i = 0; i < n; i++) {
    cout << arr[i] << " ";
}
特点；浪费内存，非常安全

方案B：用真正的动态内存（进阶）
// 进阶写法，仅供参考
int n;
cin >> n;
int* arr = new int[n]; // 用户输入几，就申请多大
// ...用完记得 delete[] arr;

方案C：现代C++终极解法
#include <vector> // 需要引入这个头文件

// ...
int n;
cin >> n;
vector<int> arr(n); // 创建一个大小为 n 的数组，且自动初始化为 0

for (int i = 0; i < n; i++) {
    cin >> arr[i];
}
// 你甚至可以直接用 arr.push_back(数值) 往后面追加元素，它会自动扩容！
